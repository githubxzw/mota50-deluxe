# 🏰 魔塔50层 · 精修版

基于《魔塔50层》复刻工程（../mota）的全面视觉升级版：HD 重绘贴图、程序化精修环境、
玻璃拟态 UI、战斗特效。玩法逻辑与原版完全一致（引擎未改动）。

## 运行

```bash
python3 -m http.server 8872
# 打开 http://127.0.0.1:8872/index.html
```
（也支持直接双击 index.html，支持 file:// 协议）

## 视觉升级内容

### 美术（tools/gen_art.py 一键生成 → assets/img-hd/）
- **HD 增强**：原版全部素材（勇者/65 种怪物/NPC/道具/地形）3 倍分辨率重制：
  平滑放大 + 提饱和 + 锐化 + 深色描边 + 顶部受光，角色从背景中跳出
- **环境精修**（程序化绘制）：错缝砖墙（含明暗/高光/凹槽）、石板地面（4 变体防平贴）、
  金属框魔门（发光锁孔）、深浅楼梯（方向光晕+箭头）、水晶球祭坛、
  暗墙带细微裂纹（可被观察发现，还原原版设定）
- 大龙/乌贼 BOSS 贴图 2 倍重制并加行走动画帧

### 渲染（game.js）
- Retina 2x 画布 + 高质量平滑采样
- 角色/怪物/NPC/道具脚下软投影
- 道具呼吸浮动 + 按类型着色的柔光辉环
- 战斗打击反馈：受击白闪、伤害/金币飘字、重伤画面震动
- 楼层转场淡入淡出、全画面暗角、移动路径金点

### UI（style.css / index.html）
- 暗色玻璃拟态卡片（backdrop-blur）、金色渐变标题与楼层徽章
- 属性图标化（❤⚔🛡✦）、圣物金边徽章、日志分级左边线
- 对话框：NPC 头像 + 打字机逐字效果（点击补全/推进）
- 弹窗弹入动画、主按钮渐变发光
- 手机适配完整保留（手势/长按连走/安全区/紧凑布局）

## 玩法与操作

与原版一致，详见 ../mota/README.md。快捷键：方向键/WASD 移动、
空格对话、X 手册、T 工具箱、F 楼传；手机支持画布滑动与虚拟方向键长按。

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `index.html` / `style.css` | 精修版界面 |
| `game.js` | 前端（HD 渲染 + 特效 + 原有交互逻辑） |
| `mota.js` / `mota-data.js` | 引擎与数据（与原工程一致，未改动） |
| `tools/gen_art.py` | 美术生成管线（改参数后重跑即可再生成素材） |
| `assets/img-hd/` | 生成的 HD 素材（env.js 为环境图集清单） |
| `test.js` | 引擎测试（83 项全部通过） |

## 重新生成素材

```bash
../mota/.venv_img/bin/python3 tools/gen_art.py
```
